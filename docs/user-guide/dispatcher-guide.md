# Руководство диспетчера / Администратора

## Обзор системы

LogiShift предоставляет мощные инструменты для управления сменами водителей, парком техники и отслеживания производительности.

---

## 🔐 Роли пользователей

### Доступные роли:

1. **Диспетчер (Foreman)**
   - Управление сменами
   - Просмотр статистики
   - Редактирование смен
   - Управление водителями, техникой и объектами

2. **Администратор (Admin)**
   - Все возможности диспетчера
   - Плюс управление настройками организации
   - Управление пользователями
   - Доступ к системным настройкам

3. **Водитель (Driver)**
   - Начало и завершение смен
   - Загрузка фотографий
   - Просмотр истории смен

---

## 📊 Главная панель (Dashboard)

### Статистика в реальном времени

На главной панели вы видите:

#### Карточки статистики

- **Активные смены** - количество текущих смен
- **Водители онлайн** - количество водителей с активными сменами
- **Техника в работе** - количество занятой техники

#### Индикаторы использования лимитов

- **Использование техники** - текущее / лимит
  - 🟢 Зеленый: < 70% использования
  - 🟡 Желтый: 70-90% использования
  - 🔴 Красный: > 90% использования
  - ∞ Безлимитный тариф

- **Использование водителей** - текущее / лимит
- **Использование объектов** - текущее / лимит

#### Текущий план

Показывает название вашего тарифного плана и ссылку на биллинг.

### Активные смены (детали)

Список всех текущих смен с информацией:
- Имя водителя
- Техника
- Объект работ
- Время начала смены

## 🚛 Управление техникой (Fleet)

### Просмотр парка техники

**Меню:** Главная → Техника

Вы увидите таблицу со всей техникой:

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор |
| Название | Марка и модель техники |
| Гос. номер | Регистрационный номер |
| Статус | Доступна / Занята |
| Активные смены | Количество активных смен |

### Добавление новой техники

1. Нажмите кнопку **"Добавить технику"** (⊕)
2. Заполните форму:
   - **Название** - например, "Экскаватор Hitachi"
   - **Гос. номер** - например, "А123БВ777"
   - **Описание** - опционально
3. Нажмите **"Сохранить"**

### Редактирование техники

1. Найдите технику в списке
2. Нажмите кнопку редактирования (✏️)
3. Измените необходимые поля
4. Нажмите **"Сохранить"**

### Удаление техники

⚠️ **Важно:** Нельзя удалить технику, на которой есть активные смены.

1. Найдите технику в списке
2. Убедитесь, что у нее нет активных смен
3. Нажмите кнопку удаления (🗑️)
4. Подтвердите удаление

### Освобождение занятой техники

Если техника показывает "Занята"但实际上 свободна:

1. Откройте детали техники
2. Проверьте список активных смен
3. Если смен нет, но статус "Занята" - техника "зависла"
4. Нажмите **"Освободить"** для принудительного сброса статуса

## 👥 Управление водителями (Drivers)

### Просмотр водителей

**Меню:** Главная → Водители

Таблица водителей показывает:

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор |
| ФИО | Полное имя водителя |
| Телефон | Контактный номер |
| Активен | Да/Нет |
| Техника | Назначенная техника (опционально) |
| Последняя активность | Дата последней смены |

### Добавление водителя

1. Нажмите **"Добавить водителя"** (⊕)
2. Заполните форму:
   - **ФИО** - полное имя
   - **Телефон** - номер телефона
   - **Email** - электронная почта (опционально)
   - **Роль** - выберите роль (Водитель/Диспетчер/Администратор)
   - **Пароль** - создайте временный пароль
   - **Активен** - поставьте галочку для активации
3. Нажмите **"Сохранить"**

### Редактирование водителя

1. Найдите водителя в списке
2. Нажмите кнопку редактирования (✏️)
3. Измените необходимые данные:
   - ФИО
   - Телефон
   - Email
   - Роль
   - Статус активности
4. Водитель может сменить пароль самостоятельно
5. Нажмите **"Сохранить"**

### Деактивация водителя

1. Найдите водителя
2. Нажмите редактирование (✏️)
3. Снимите галочку **"Активен"**
4. Нажмите **"Сохранить"**

**Важно:** Деактивированный водитель не может войти в систему.

### Удаление водителя

⚠️ **Важно:** Нельзя удалить водителя с активными сменами.

1. Найдите водителя в списке
2. Убедитесь, что у него нет активных смен
3. Нажмите кнопку удаления (🗑️)
4. Подтвердите удаление

## 📋 Управление сменами (Shifts)

### Просмотр всех смен

**Меню:** Главная → Смены

Таблица показывает все смены с фильтрами:

| Колонка | Описание |
|---------|----------|
| ID | Уникальный идентификатор |
| Водитель | Имя водителя |
| Техника | Марка и модель |
| Объект | Название объекта |
| Статус | Активная / Завершена |
| Время начала | Дата и время начала |
| Время окончания | Дата и время окончания (если завершена) |
| Часы | Отработанные часы |
| Зарплата | Начисленная сумма |
| Комментарий | Комментарий к смене |

### Ручное создание смены

Если водитель не может создать смену самостоятельно:

1. Нажмите **"Создать смену вручную"** (⊕)
2. В появившемся модальном окне:
   - **Водитель** - выберите из списка (показываются только свободные водители)
   - **Техника** - выберите из списка (показывается только свободная техника)
   - **Объект** - выберите из списка (показываются только активные объекты)
3. Нажмите **"Создать"**

**Важно:**
- Списки автоматически фильтруются:
  - Водители без активных смен
  - Свободная техника
  - Активные объекты
- Водитель увидит созданную смену в своем приложении

### Редактирование смены

Вы можете отредактировать любую завершенную или активную смену:

1. Найдите смену в списке
2. Нажмите кнопку редактирования (✏️)
3. В модальном окне вы можете:
   - **Изменить водителя** - выбрать другого водителя
   - **Изменить технику** - выбрать другую технику
   - **Изменить объект** - выбрать другой объект
   - **Загрузить фотографии** - загрузить фото одометра/накладной от имени водителя
   - **Добавить комментарий** - добавить примечание к смене
   - **Изменить время** - скорректировать время начала/окончания
4. Нажмите **"Сохранить"**

### Загрузка фотографий при редактировании

В модальном окне редактирования смены:

**Фотографии текущей смены:**
- **Начало работы (одометр)** - загрузите фото перед работой
- **Конец работы (одометр)** - загрузите фото после работы
- **Накладная** - загрузите фото накладной

**Как загрузить:**
1. Нажмите кнопку **"Загрузить"** под нужным типом фото
2. Выберите фото с устройства
3. Дождитесь загрузки (появится индикатор прогресса)
4. После успешной загрузки появится ссылка **"Просмотр"**

**ℹ️ Важно:** Система автоматически определяет тип фотографии на основе того, какую кнопку вы нажали:
- Кнопка под "Начало работы" → тип `odo_start`
- Кнопка под "Конец работы" → тип `odo_end`
- Кнопка под "Накладная" → тип `invoice`

Это гарантирует, что фото попадет в правильное поле смены.

### Удаление смены

⚠️ **Осторожно:** Удаление смены необратимо.

1. Найдите смену
2. Нажмите удаление (🗑️)
3. Подтвердите удаление

## 🔄 Типовые рабочие процессы

### Сценарий 1: Водитель забыл загрузить фото

**Проблема:** Водитель завершил смену, но забыл загрузить фото накладной.

**Решение:**
1. Откройте **Смены**
2. Найдите нужную смену
3. Нажмите **Редактировать** (✏️)
4. В разделе **"Накладная"** нажмите **Загрузить**
5. Загрузите фото (водитель может прислать его в мессенджер)
6. Нажмите **Сохранить**

### Сценарий 2: Техника "зависла" в занятом состоянии

**Проблема:** Техника показывает как занятая, но смен нет.

**Решение:**
1. Откройте **Техника**
2. Нажмите на технику с проблемой
3. Проверьте список **Активные смены** - он должен быть пустым
4. Если смен нет, нажмите **Освободить**
5. Техника станет доступной

### Сценарий 3: Создать смену за водителя

**Проблема:** Водитель не может использовать приложение (нет интернета, сломался телефон).

**Решение:**
1. Откройте **Смены**
2. Нажмите **Создать смену вручную** (⊕)
3. Выберите:
   - Свободного водителя
   - Свободную технику
   - Активный объект
4. Нажмите **Создать**
5. Водитель увидит смену в своем приложении

### Сценарий 4: Изменить данные в завершенной смене

**Проблема:** Водитель отработал на другой технике, а не на той, что в системе.

**Решение:**
1. Откройте **Смены**
2. Найдите смену
3. Нажмите **Редактировать** (✏️)
4. Измените **Технику** на правильную
5. Добавьте **Комментарий**: "Изменено диспетчером"
6. Нажмите **Сохранить**

## ⚠️ Частые проблемы

### "Не могу освободить технику"

**Причина:** На технике есть активные смены.

**Решение:**
- Завершите или удалите все активные смены на этой технике
- Только потом освобождайте технику

### "Водитель не видит технику в списке"

**Причины:**
- Техника занята другой сменой
- Техника деактивирована

**Решение:**
- Проверьте статус техники
- Освободите технику если необходимо

### "Не могу добавить водителя"

**Причина:** Достигнут лимит водителей по тарифу.

**Решение:**
- Проверьте лимиты в **Настройках** → **Тарифный план**
- Обновите тариф или деактивируйте неиспользуемых водителей

### "Графики не показывают данные"

**Причина:** Нет смен за выбранный период.

**Решение:**
- Убедитесь, что смены созданы
- Проверьте период выборки

1. **Мониторинг лимитов**
